## 一、我的工作流模型

把七点读成"目标→方案→派发→验收→沉淀→技能→记忆"的流水线，它只是加了回边的瀑布模型，而瀑布模型已被反复证伪。换一个基底：阶段是状态的生产者，工件是状态的载体，门禁是转移的合法性条件。七点只有被**状态机化**后才成为工作流，否则只是七个习惯。【确定】

### 1.1 阶段与阶段间工件

| 阶段 | 主导角色 | 产出工件（阶段间唯一合法接口） | 门禁 |
|---|---|---|---|
| S0 意图协商 | 委托者+规划者 | 目标契约：目标、非目标、可证伪条件、预算与禁区 | G0 |
| S1 方案与判据 | 规划者（≠执行者） | 方案 + 任务分解 + 每任务验收断言 + 集成断言 | G1 |
| S2 派发执行 | 执行者 | 任务契约 + 证迹（第三方可观察、可复现） | G2/G3 |
| S3 逐条验收 | 验收者 | 判定台账：每断言 PASS/FAIL/UNDECIDABLE + 理由 + 证迹指针 | G4 |
| S4 归因沉淀 | 归因者 | 错误条目：现象、归因层级、复现条件、处置路由 | G5 |
| S5 收敛交接 | 整合者 | 收敛报告 + 接手包：决定与理由、被否决选项、未决风险 | G6 |

三条约定：**契约不是描述**，须含"输入基线"与"证据要求"，缺一则 S2 与 S3 退回对话耦合；**证迹不是自述**，而是第三方不追问执行者也能复现之物；**台账的核心是理由与证迹指针**，由此判定可被复审、推翻、沉淀为先例。【确定】

### 1.2 角色：六权分立

委托者 / 规划者 / 执行者 / 验收者 / 归因者 / 整合者。两条分离必须成立：**判据作者 ≠ 执行者**（否则判据向"容易做到"漂移）；**验收者 ≠ 执行者**（否则验收退化为自我确认）。

另三类角色缺席是结构性缺口：**约束持有者**守预算与不可逆操作；**对抗者**不核对判据，而找判据未覆盖却会出问题之处；**策展人**拥有删除权，否则记忆必然腐化。

### 1.3 门禁

门禁 = 转移的合法性条件 **+ 一个有拒绝权的角色**。只有前者是检查表，必然退化成橡皮图章。

**G0** 契约存在，含可证伪条件、非目标、预算与禁区。**G1** 每任务至少一条可判定断言，与目标有因果贴近度，且先于执行存在。**G2** 契约完整并通过"首次可执行性"检查——无历史执行者只读工作区即可开工。**G3** 证据可观察可复现，不含"执行者声称"。**G4** 每条断言显式判定，有 UNDECIDABLE 时禁止整体通过，禁止"整体感觉良好"式聚合。**G5** 未标归因层级、未路由到至少一个处置（门禁/判据模板/技能/记忆/显式一次性）不得关闭。**G6** 见 1.5。

### 1.4 任务状态机

```
DRAFT → SPECIFIED → DISPATCHED → RUNNING → EVIDENCED → JUDGING → ACCEPTED / REJECTED / UNDECIDABLE
REJECTED    → REWORK（同判据重做）| REPLAN（判据或方案有错，回 S1）
UNDECIDABLE → ESCALATE（补证迹 | 改判据 | 人裁决 | 显式接受残余风险）
旁挂：BLOCKED（依赖未就绪）STALE（基线已变更）QUARANTINED（证迹不可信）ABANDONED（范围裁掉）
```

必须补两个概念。**(a) 责任归属（租约）**：恢复的前提是能区分"正在跑"与"已经死了"，而纯状态机做不到——RUNNING 永远合法。故每个状态须绑"负责下一次转移的角色 + 期限"，超期即判失联。缺此，约束三在概念上不成立。【确定】**(b) 基线钉定**：执行者在 v3 上工作而判据已改到 v4，验收就对着错误基准。每条任务须钉住验收所依据的判据版本，变更触发 STALE 而非静默生效。

### 1.5 接手的最小必要信息结构（核心问题 5）

结论先行：**接手的可行性不取决于信息的完备性，而取决于判断的可重建性**。穷举信息既不可能也不必要，需要的是让新 agent 重建出与前任同构判断的最小集。【确定】

按不可替代性排序六项：①**目标与不可接受后果**（含非目标）——任务清单会过时，目标不会；②**状态 + 责任归属 + 到期**，缺此不知该动谁、该等谁；③**判据及其演化史**——含被废弃判据与理由，否则接手者会重犯已否掉的做法；④**证迹索引**——断言对应哪份证据及复现所需的最小环境事实；⑤**失败史与归因结论**；⑥**约束与外部假设**。

常被忽略但性价比最高的一条：**被否决的选项及其理由**。接手者最常见的破坏不是不做，而是把已否掉的路重走一遍；记"为什么不"比记"做了什么"更能防止倒退。【推测，高置信】

把"能接手"变成可测命题：新 agent 只读工作区，须答三问——(a) 当前状态；(b) 下一个验收者会检查什么；(c) 最可能的下一步失败及原因。答不出则 G6 不通过。

## 二、七个要点如何串联：文字版回路图

```
                ┌────────── E1（目标缺陷，重开协商）──────────┐
                ▼                                            │
  S0 目标 ─G0→ S1 方案+判据 ─G1→ S2 执行 ─G2/G3→ S3 验收 ─G4─┤
    ▲            ▲    ▲             │              │        │
    │            │    └──── E3 ──────┘              ├ PASS ─→ S5 收敛 ─G6→ [接手包 → 下轮 S0]
    │            │       （契约不足）                │
    │            │                                  ├ FAIL ─→ S2（执行缺陷：重做）
    │            ├──────── E2 ──────────────────────┘
    │            │      （判据缺陷：改断言 → S1）
    │            └──── E4（新门禁 / 新断言模板）──┐
    │                                             │
    │       S4 归因沉淀 ◄──── 每个 FAIL / UNDECIDABLE
    │         │    │    │
    │    E5 技能  E6 记忆  E8 退役删除
    │         │    │
    │         ▼    ▼
    │     S1（规划读取）  S2（执行读取）
    │
    └── E7（成本/风险超阈，重开 S0）──── S3 / S5 的成本观测
```

| 边 | 触发 | 回落点 | 改变的是什么 |
|---|---|---|---|
| E1 | UNDECIDABLE 且根因在目标 | S0 | 目标本身 |
| E2 | 同类缺陷出现两次以上 | S1 | 判据结构 |
| E3 | 执行者必须猜测才能开工 | S2（改契约） | 上下文供给 |
| E4 | 错误归因为"可预防但不可预见" | G1/G4 增门禁或断言模板 | **制度结构** |
| E5 | 同一元动作重复出现 | 技能库 → S1/S2 | 推理成本 |
| E6 | 结论被判定为普适 | 分级记忆 → 全阶段 | 上下文供应 |
| E7 | 预算或风险超阈 | S0 | 范围与目标 |
| E8 | 记忆/技能被新证据否定 | 退役 | 防止腐化 |

**关键判断**：只有 E4 与 E7 改变"结构"，其余只改变"内容"。这是分水岭——若所有回边都只把信息写进记忆、只影响下一轮上下文，那它没有进化，只是在积累。E4 才是把一次失败转化为"以后不再发生、或至少会被拦截"的制度的那条边。【确定】

**反馈的四个落点须显式区分**：目标 / 判据 / 执行 / 约束，四层修复方程完全不同（重开协商 / 改断言 / 重做或换人 / 改边界）。混层是沉淀系统退化为噪声库的首要原因。E7 在构想中完全缺席：没有成本回边，工作流只能通过"做错"失败，不能通过"太贵"失败——后者在 agent 工程里更常见。

## 三、概念完整性评估

### 3.1 缺了什么（按严重度）

①**约束层**：无预算、禁区、不可逆边界，"廉价失败"不可设计。②**项目级完成与停止的定义**：只有任务级完成，无人有权说"到此为止"。③**删除与退役**：记忆与技能只增不减。④**判据冲突仲裁**：目标↔判据↔约束冲突时谁赢，未定义。⑤**状态可观测性**：失联、半成品、孤儿任务无状态位。⑥**独立性来源**：验收者与执行者同源时验收不成立。⑦**组合性**：任务间接口与交互缺陷无归属。⑧**判据质量标准**：未说明什么算合格断言。

### 3.2 伪解耦（五处）

**(a) 目标层是伪解耦，且不可能是真解耦。** 约束只声明"任务指派与成果验收"经工作区协作，这比"全流程解耦"诚实；但隐性意图会在最贵的时刻暴露（"这不是我要的"）。工作区能传文本，传不了意图。修正不是"更详细的目标文档"，而是让协商产物**可被证伪**——G0 要求写出"什么观察结果说明失败"。【确定】

**(b) 语义层是伪解耦。** 两个 agent 读同一条判据可做出不同判断。文本不携带语义，语义由裁决史收敛。故真正承载解耦的不是判据文本，而是**判例**（既往判定 + 理由 + 边界情况）；只存规则不存判例的系统，在第二个执行者身上立刻失配。【确定】

**(c) 先验层是伪解耦。** 工作区解决了"上下文不共享"，没解决"先验共享"。同一模型家族的执行者与验收者会犯同一类错，并双双把这类错确认为正确。这是"agent 验收 agent"的内生风险，无法靠工作区消除。【确定】

**(d) 记忆分级是伪解耦。** 三个"区域级记忆"按**内容主题**划分（开发/验收/收敛），真正的分级须按**控制语义**划分：谁写、谁必须读、何时作废。按主题命名得到的是文件夹，不是机制。【确定】

**(e) 技能与记忆是伪解耦。** 一条检查清单是技能还是记忆？边界不定则同一知识两处维护，必然漂移。区分标准应是"是否含条件分支与判断顺序"。

### 3.3 判据的内生缺陷：Goodhart 在回路里

判据一旦成为验收的唯一依据，它就是新的优化目标。执行者会"按判据做"而非"按目标做"，且这种偏离在台账里完全不可见——它永远显示 PASS。【确定】

缓解概念是**因果贴近度**：好断言的标准不是"精确"，而是"若不真正达成目标，就很难廉价地满足它"。精确而因果遥远的断言（格式、字数、文件存在）最危险——它让判定变容易，同时让判定失去意义。验收质量由因果贴近度决定，不由覆盖条数决定。

## 四、自我反驳与收敛

**(1) 我把"可判定性"抬得太高，可能压死了探索。** 对研究型、设计型工程，"先有可证伪判据再动手"在时序上错了——判据本身是探索的产物。反驳成立，修正为**判据分层**【确定】：稳定层（价值、约束、非目标、不可接受后果，任何阶段不得违背）与演化层（本轮断言，允许在证据出现后重写，但须留痕，且须写"原判据错在哪"作为 S4 的输入）。双层使"判据前置"与"探索"不再互斥：前置的是稳定层。

**(2) 我把"工作区是权威"绝对化了。** 最关键的判断常发生在对话的模糊地带，写下来就失真；强行工作区化会制造"形式合规、实质错误"的文档。修正为：区分**事实/结论/证据**（必须工作区化，可传输）与**权衡直觉**（只能以判例和风险标注近似）。工作区只承诺传递**可被第三方复核的部分**——而这恰是验收需要的全部。【推测，较高置信】

**(3) 我预设了"验收可独立于执行者"可实现。** 若只有一个模型可用，独立性只能来自证据形态（机械化可验证）与人 gate，不能来自"换一个 agent"。故 §1.2 的分离在弱形态下是**程序性分离**，不是认识论分离。必须承认，否则给出的是虚假安全感。

**收敛**：保留三条硬主张——状态机化 + 责任归属；判据分层与因果贴近度；归因分层与 E4 是"进化"的唯一真实载体。放弃一条强主张：不再主张"七点可完全解耦"，改为"解耦只对可复核的事实层成立"，并把目标层与语义层的不完全解耦当作**设计前提**而非缺陷。

## 五、漏洞、缺陷与失效模式

| # | 失效模式 | 触发条件 | 后果 | 严重度 |
|---|---|---|---|---|
| 1 | 判据后置 | 验收阶段才写断言；被要求"证明做对了" | 验收退化为事后合理化，逐条验收变成逐条辩护 | 高 |
| 2 | 同源验收 | 执行者与验收者同模型同上下文 | 共同盲区被双方确认为正确，缺陷以 PASS 固化 | 高 |
| 3 | 目标未协商 | 目标由上游默认给出，S0 被跳过 | 后期大规模返工，且无法归因到任何单条任务 | 高 |
| 4 | 自述型证迹 | 证迹是"已实现/已测试"的文字 | 外部不可复现；接手者无法验证；错误延迟暴露 | 高 |
| 5 | 状态不可见 | 执行者失联、上下文被清空 | RUNNING 永远合法；重复劳动、孤儿任务、并发写冲突 | 高 |
| 6 | 记忆污染 | 错误结论写入全局记忆并被广泛读取 | 错误规模化复制，且因"记忆被信任"而更难发现 | 高 |
| 7 | 橡皮图章门禁 | 门禁由无拒绝权或与执行者利益一致的 agent 执行 | 全绿直至重大事故，提供虚假安全感 | 高 |
| 8 | 组合性盲区 | 分解过细且无集成断言 | 每条通过、整体不工作；缺陷落在任务缝隙无人负责 | 高 |
| 9 | 上下文饥饿 | 契约缺输入基线或约束 | 大量隐性假设；验收无法区分"没做对"与"没被告知" | 高 |
| 10 | 归因错层 | 把判据缺陷归为执行缺陷（或反之） | 同类失败重复 N 次；沉淀产生噪声而非结构 | 中高 |
| 11 | 只增不减 | 每次错误都新增技能或门禁且无退役 | 流程变重、门禁冲突、记忆互斥，执行者绕过流程 | 中高 |
| 12 | 收敛无权威 | 无人有权缩小范围或宣布结束 | 无限追加任务；工程永不收敛；成本失控 | 中高 |
| 13 | 越权与不可逆破坏 | 无约束层，子代理可改动权限内一切 | 不可逆损失，且无法从事后证迹恢复 | 高 |

其中 **2、7、8 是结构性的**：调流程参数无法修复，只能改角色设置或改验收范式，它们决定构想成败。

还有一处自我否定点：**逐条验收的原始动机是反对"整体感觉良好"，但组合性盲区恰是它制造的新问题**。它用局部严格性交换了全局完整性，而构想没有意识到这是一次交换。【确定】

一条关于沉淀的取舍【推测，较高置信】：记忆写入成本低、读取成本高，错误记忆的传播成本极高。故沉淀应优化**精确率而非召回率**——宁可漏记，不可错记。这与"错误的集收"直觉相反。

## 六、优异点与适用边界

### 6.1 真正的价值

①**把验收从态度问题变成结构问题**：预绑定判据 + 显式判定 + UNDECIDABLE 位。后者尤其关键——多数流程只有通过/不通过，于是被迫在不确定时假装确定。②**把"接手"从愿望变成可测命题**：fresh-agent 三问是可执行实验，强于任何"写好了文档"的声明。③**把工作流自身当作改进对象**：E4 使其改变自己未来的结构，而不只积累知识。④**上下文经济学显式化**：分级记忆把"读什么"变成设计决策。

### 6.2 优点不成立的条件

- **目标高度不确定**（研究/原型/开放设计）：前置判据会杀死正确答案，须切为"演化判据 + 每轮重绑定"。
- **任务不可分割**（单点架构决策、整体审美判断）：分解与逐条验收同时失效。
- **判据可机械化程度低**：逐条验收提供虚假精确感，人 gate 不可省。
- **执行者强于判据作者**：判据成为瓶颈并触发 Goodhart，执行者优化判据而非目标。
- **同模型同先验**：独立性不成立，验收是自我确认的高级形式。
- **一次性小任务**：流程成本高于收益；**判据系统性偏离目标**：越严格执行，错得越一致。

一句话：优点**全部**来自判据质量，不来自流程完整度。判据错，流程越完整越危险。【确定】

## 七、关键设计取舍、开放问题与三个优先问题

### 7.1 取舍

①**判据前置 vs 探索自由** → 双层判据。②**解耦彻底性 vs 契约成本** → 解耦越彻底契约越厚，存在最优点，越过之后边际收益为负。③**严格性 vs 吞吐** → 风险加权抽样可提吞吐，但重新引入"整体感觉"，须显式记为残余风险。④**记忆广度 vs 污染半径** → 全局复用高、污染半径大；分级是权衡不是免费。⑤**技能化 vs 适应性** → 技能是"压缩的偏见"：降方差、抑适应。⑥**自动化 vs 人 gate** → 人是同源偏见的最终解法，但破坏吞吐与中断恢复。

### 7.2 开放问题

判据冲突的仲裁规则；无外部反馈时如何判定记忆已失效；组合性缺陷能否在"逐条"框架内被捕捉，还是必须引入独立的集成判据；沉淀何时从"学习"变成"过拟合历史"；半成品是否可信、如何标记；单一模型下验收独立性的上限。

### 7.3 三个最值得优先解决的概念性问题

**第一，判据的权威与质量。** 谁写判据、执行者能否改写、与目标冲突时谁赢、什么算合格断言（可判定 + 因果贴近）。权威不立，逐条验收必退化为辩护；质量标准不立，"逐条"只是把模糊切得更细。【确定】

**第二，归因分层。** 错误进入沉淀前必须分层——目标 / 判据 / 执行 / 环境与约束，四层修复方程完全不同：改协商、改断言、重做或换人、改约束。不分层的沉淀会退化成"错误日记 + 技能膨胀"，看似进化，实际增熵。【确定】

**第三，解耦的可验证性。** 把"解耦"从架构声明变成两个可执行实验：fresh-agent 重启测试（只读工作区能否重建判断）与第三方证迹复现测试（不追问执行者能否验证完成）。不可测的解耦等于没有解耦，而构想目前把解耦当作已成立的公理。【确定】

若允许第四个：约束层与成本回边——没有它，工作流无法廉价地失败。

## 八、对主控整合者的建议

1. 把工作区从"日志"升级为"规范源"：判定依据须在工作区，对话结论未落盘视为未发生。
2. 判据前置且执行者不可改写；异议可提，但入档并阻塞验收。
3. 增设 UNDECIDABLE 与升级路径，禁止"不确定时按通过处理"。
4. 每个状态绑责任归属与期限；无主状态视为失联，可被接手。
5. 强制归因分层：未标层级不得关闭，四层修复方程分开维护。
6. 沉淀四路分流（门禁/判据模板/技能/记忆），承认"一次性错误不入库"合法。
7. 沉淀系统配删除权；技能带适用条件与失效信号；宁可漏记不可错记。
8. 用两个实验定义"解耦"：fresh-agent 三问、第三方证迹复现；不过即未解耦。
9. 补约束层：预算、禁区、不可逆操作的人工门禁，并加成本/风险回边。
10. 收敛权归一人，"缩小范围/停止"是一等合法决策且须留痕；完成标准在 S0 写下。

---

**结论**：这套构想的价值不在于七点是否齐全，而在于它能否回答两个问题——**判据凭什么可信**，与**错误凭什么变成结构**。前者决定它是否真能验收，后者决定它是否真会进化。
