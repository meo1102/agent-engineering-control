## 1. 总判断：方向修正正确，但承重点换错了

一句话：**v0.4 的问题是学习太少，本轮构想的问题是生长太多；二者的正解不是折中，而是把承重点从"何时学"换成"学到的东西可以改变什么"。**

【确定】本轮最有价值的一处，不是"学习成为常设责任"这个口号，而是它无意中暴露了 v0.4 的一个隐藏假设：**v0.4 冻结的是时间，而基线稳定性真正需要冻结的是对象与权威。** 一旦看清这一点，"不学习则集群不生长、边学边改则基线不稳"这个看似二难的张力就自动消解——学习可以在任何时刻发生，只要它不能改写已钉版的验收对象、判据、权限与门禁。这是我认为本轮唯一值得付出结构代价去换的东西。

但本轮同时撤掉了 v0.4 唯一那道保护，却没有给出等价替代。于是问题从"学习太晚"变成"学习没有边界"：没有预算、没有停止规则、没有"不生长"的合法状态。一个不能停的系统无法证明自己变强了，只能证明自己变多了。

### 1.1 继承（不改）

目标锚与事实锚双锚点；自验非验收；判据信任根；回退半径 r1–r4；证据阶梯；三本账；交付闭合与学习闭合分离（但把"闭合"的解释从时间先后改为权威不同）。【确定】本轮没有任何论证足以推翻它们。

### 1.2 冲突与裁决

| 冲突 | v0.4 | 本轮 | 我的裁决 |
|---|---|---|---|
| 学习时点 | 验收后批次 | 常设责任 | **采纳，但改为对象冻结** |
| 人类权力 | 多门保留 | 收缩为三项 | **拒绝收缩，补第四项** |
| 工作区地位 | 证据容器 | 生长环境/记忆/落地 | **采纳，但须先分离证据与记忆** |
| 组织形态 | 角色链 | 集群/种群 | **有条件采纳：无淘汰则不成集群** |
| 进化对象 | 延后 | 常设 | **采纳，但须分知识层与制度层** |

### 1.3 三处修正

**修正一：时间冻结 → 对象冻结 + 权威隔离。** 验收基线钉版即不可变；学习此后随时可进行，但只能写入影子账与候选区。这样既不等待验收，也不边做边改。【确定】概念上同时满足两个约束。

**修正二：人类补一项"反例指定权"。** 这是本轮最关键的一处。保留给人类的三项权力——方向、目标、真实使用验收——全部是**回答型**权力：它们回答集群提出的问题。而提问权、选项构造权、节奏权全在集群手里。人只被允许在别人画好的框里回答，无论框多精美，都不是问责，是背书。补一项最便宜的权力即可破局：人类可在任一时刻指定"什么现象出现就算失败"，该指定强制进入当期判据。【推测】一句话的信息成本，结构性效果强于十道审批。

**修正三：给生长配预算、停止规则与"不生长"的合法状态。** 见 §5.5 与 §8。

### 1.4 对前三轮结论的自我批判

先承认方法论问题。【确定】v0.2–v0.4 都由"同模型两席 + 共享材料 + 整合者裁决"构成，REPORT-v3 §2 已诚实标注这不是异构验证。但四轮下来，同一批概念被反复确认为"共识"，确认次数在缺乏外部检验时被当成了置信度。这与我将在 §10 攻击的 Goodhart 是同一个病：**用可计数的活动（席位数、共识条数、文档节数）替代不可计数的东西（是否正确）。** 我这一席也在参与这个仪式；我的"独立"是程序性的，不是认识论的。这是本报告全部结论的上限。

三条具体误判：

1. **把激励当待办，而不是结构。** docs/07 Q13 提出"偏差申报如何激励相容"，v0.2–v0.4 一路把它留在开放问题里。但三轮所有学习机制（错误台账、观察、晋升）都建在"错误被如实报告"之上。这不是待办，是承重墙。【确定】在一个前提未被满足时扩大建立在该前提上的机制，等于放大该前提的缺陷。本轮把学习从批次改为常设，是最典型的一次放大。

2. **把工作区当证据源，而不是证据的存放处。** v0.4 §7.2 措辞谨慎，说工作区是"受验产物与证据的共同入口"，但通篇仍把"直接检查工作区"当作独立性来源。工作区是 agent 写的；检查 agent 写的文件，得到的仍是 agent 的产物。独立性的来源只能在外部——真实使用者、第三方、物理后果、外部系统。**工作区能提高证据的可复核性，不能提高证据的独立性。** 这条前三轮都没切干净。

3. **假设"有权威的人类"存在。** v0.4 反复说"不得默认通过""预算不足时缩小范围"，但从未处理人类缺位、无能、利益冲突的结构解。全部问责挂在这个未验证的主体上。本轮把人类权力收缩到三项，等于在这个薄弱支点上再加重量。

## 2. 三元框架：责任、权利、接口、失败路径

### 2.1 三元不是三个平权节点，是三种不可互换的失败

【确定】它们的区别不在谁更重要，而在**三者以不同方式失败，且一种失败不能被另一种补偿**：人类失败是"要错了"，集群失败是"做偏了或学歪了"，工作区失败是"没人能看见真相"。用更多 agent 补偿价值错误、用更多文档补偿工作区不可读，都是错配。

### 2.2 不可转移责任（附"转移后失去什么"）

| 主体 | 不可转移责任 | 一旦委托，失去的是 |
|---|---|---|
| 人类 | 目的与价值排序 | 无人能说"这不该做" |
| 人类 | 可接受损害边界（含第三方） | 损害由未参与决策者承担，问责无对象 |
| 人类 | 反例指定权 | 判据自我封闭，系统不可证伪 |
| 人类 | 遗留接受与停止/放弃 | 项目永不结束，或永远"差一步" |
| 人类 | 元规则变更 | 自改宪法 |
| 集群 | 转换忠实性（意图→可检验产物） | 一切失败都可归因于"人类没说清" |
| 集群 | 举证与自曝不确定性 | 证据退化为自述 |
| 集群 | 变异生产与候选构造 | 无变异，只有重复 |
| 集群 | 免疫（检测自身污染、趋同、自噬） | 越学越僵且无人察觉 |
| 工作区 | 保存实际存在过的东西（含否决与干预） | 历史可被重写 |
| 工作区 | 使"看现场"可能 | 人类只能看摘要 |
| 工作区 | 承载落地状态与运维责任 | 落地退化为"文件齐全" |

可委托的是**劳动而非权威**：事实核查、局部可逆判断、证据去重、选项分析、候选构造、预授权内的常规门禁、带审计的记忆策展、技能维护、路由排期。

### 2.3 六个接口，及最容易被伪造的一处

人类→集群（方向/目标/非目标/可接受损害/反例）；集群→人类（**可裁决的问题包**）；集群→工作区（带可见性状态的写入）；工作区→人类（**现场**，非加工品）；工作区→集群（带权威标签的记忆与约束）；人类→工作区（落地接受、运维交接、退役决定）。

【确定】接口 2 最容易被伪造：**谁构造问题，谁就决定了答案的范围。** 故它必须有硬性内容义务——精确问题、选项、每项代价、真实分歧，以及**集群自己不建议的那个选项及其最强理由**（反选项义务）。没有反选项的问题包不是问题，是提案。接口 4 同理：若不能提供至少一个未经集群加工的原始对象，"看现场"是空话。

### 2.4 三条失败路径

人类失效：唯一合法的默认是**缩小范围或暂停**，不是默认通过；且必须有 agent 可触发的"请求裁决失败"通道——超时未获实质判断即记为"未决"，项目停在原处而非滑过。集群失效：靠免疫指标与熔断（§4.6）。工作区失效：靠冷启动测试、删除测试、记忆预算与归档隔离（§3.4）。

## 3. 工作区：生长环境、记忆、落地

### 3.1 先切一刀：证据与记忆必须分层

【确定】这是本轮最需要补的结构缺口。证据的正确性标准是"完整、不可改写、可复核"，记忆的标准是"选择性、可修正、可检索"——两者相反。混在同一层会同时生两种病：证据被记忆改写（历史失真），记忆被证据淹没（检索失效）。故工作区至少五层，不是三层：

| 层 | 内容 | 可变性 | 删除权 |
|---|---|---|---|
| E 现场层 | 产物、日志、失败、干预、否决、事故 | 只追加 | 不可删，只能封存 |
| L2 观察层 | 单次事件的观察与假设 | 可修正 | 区域负责人 |
| L1 项目层 | 目标、判据、决策、判例、风险 | 版本化 | 项目 owner |
| L0 知识层 | 跨项目原则、模式、反模式 | 慢变 | 人类 |
| L3 制度层 | 门禁、角色权限、判据模板、控制流 | 极少变 | 人类 |

**L0 与 L3 必须分开。** v0.2–v0.4 把"模型/控制流/角色权限"统称元层，但知识变更（我们学到 X）与制度变更（谁有权做什么）是两种东西：前者改变判断内容，后者改变权力分配。混在一起治理，结果是要么知识晋升过重，要么门禁变更过轻。【推测】这是本轮"进化"概念最危险的地方：进化一旦包含改制度，它就不再是学习，而是政变。

工作区自身也有生命周期：**建立**（先立宪法：写域、可见性、证据只追加、每层删除权归谁）→**活跃**（事件触发写入）→**冻结**（钉版，只许追加）→**封存**（退出检索）→**考古**（显式调用旧材料）。跳过"建立"的工作区必然长成垃圾桶，跳过"封存"的工作区必然检索失真。

### 3.2 生长环境的八个性质

肥沃、有边界、可读、可追溯、可清理、可演化——六个来自 docs 传统，我再加两个，且认为它们比前六个更容易被忽略：

- **可失败**：失败能被记录而不被惩罚。缺此，工作区只积累成功叙事。
- **可停**：存在合法的"此刻无事发生"状态。多数设计隐含"必须有进展"，这直接生产活动量造假。

### 3.3 五条治理规则（合起来即工作区宪法）

1. **约束必须注入，经验才可检索。** 【确定】检索的前提是"知道自己需要什么"，而约束恰恰是"不知道自己需要"的知识。禁区、非目标、不可逆红线必须随任务强制下发；经验条目才走检索。混在一个检索系统里，等于让 agent 自己决定要不要遵守约束。
2. **负记忆优先。** 否决、事故、被证伪的规则必须可主动检索，且**立项时强制读同类否决记录**。理由很实在：人在兴奋时不会主动去查"这事以前为什么失败过"。
3. **写入配额与具名置换。** 每项目对 L0 的写入名额有限；满额时新增必须**具名置换**一条旧条目。【推测】这是对付"元知识通胀"最有效的机制：它把"增加"的成本变成"必须放弃什么"，强制比较；阈值门禁只强制等待。
4. **归档即不可见。** 归档条目默认退出检索，需显式"考古"才可见。若归档仍可被检索，"退役"只是礼貌用语。
5. **晋升需非同源复核。** 候选生成者不得为晋升批准者；L0/L3 由人类批准。

### 3.4 落地：不是验收通过，是把负担交出去

【确定】落地的准确含义是**有人接住了这个项目**。它不是文档齐全，而是四问：可用（目标使用者能独立完成，不依赖执行者在场）、可维（有具名的运维责任人与已知处置路径）、可接（陌生接手者只读工作区即可继续）、可退（存在退役路径与退役后的数据/责任处置）。再加两条：责任已接（谁接受遗留、谁承担外部性）、成本已明（运行与维护成本被写下）。

**落地权属于要承担后果的人，不只是目标所有者。** 这是我对本轮的一处明确修正。"由有权者接受"在多利益相关方场景下会退化为"由最不承担后果的人接受"。运维方、受影响第三方、合规责任人，都必须在落地裁决里有位置或代表。【推测】否则"落地"就是合法地把烂摊子转手。

## 4. 集群：作为学习与进化主体

### 4.1 定义：判据是错误相关性，不是席位数

【确定】若两个成员的失败集合高度重叠，它们是一个成员的两份拷贝。

> 集群 = 一组在**错误相关性**上可区分的执行者 + 一个共享的选择机制 + 一个共享的免疫台账。

推论一：**多角色不构成多样性。** 计划/工作/验收是分工而非异构，可由同一先验产生，因而共享同一批盲区。推论二：**同模型多席不是冗余。** 冗余价值 ≈ 1 − 失败相关系数；系数接近 1 时收益趋零而成本线性增长。这是本轮最容易被忽略的经济学事实，也是"我们上了四个 agent"这类说法最常见的自欺。

### 4.2 组成：五个轴，只有两个产生真实异质性

能力轴（强/弱）产生覆盖，角色轴（分工）产生流程，时间轴（长驻/临时）产生记忆，**先验轴与权限轴才产生错误去相关**。故异质性的正确投入方向是不同材料、不同模型、不同信息权限，而不是更多角色名。

### 4.3 变异：外部信号是唯一不同源的变异

探索预算、红队、多方案、异构模型都在集群内部，共享同一批前提；只有外部信号（真实使用、事故、第三方、物理后果）不与集群共享先验。【推测】故变异预算应向外倾斜，即使更贵更慢——它是唯一能打破共同盲区的来源。这与 v0.4 的结论一致，但理由不同：不是因为真实使用更"真"，而是因为它是唯一**不同源**的。

### 4.4 选择与淘汰：三个不可让渡的条件

选择者不得是被选者的作者；选择必须包含**杀死**的动作；杀死必须留下理由。度量上，**淘汰率为零等于没有进化**。这是我对"集群"一词最硬的检验：一个从不淘汰任何东西的集群，只是一个更大的角色链。

### 4.5 保留：载体决定可审计性

保留在记忆、技能、角色、制度、模型权重五处，可审计性依次下降、回滚成本依次上升。【推测】故我的立场是：优先把进化落在可审计载体上（技能、约束、判据模板），把权重级变更当作"换了一个主体"，要求重新验证而非继承。代价是可审计载体更慢、更不通用；但代价正是控制手段——让便宜的路难走一点，让贵的路付全价。

### 4.6 免疫与代谢：五个指标，两种对称的失败

免疫检测五事：污染（无来源/不可信来源）、趋同（独立席位实质分歧率下降）、自噬（知识来源中自身产出份额上升）、扩权（未授权行为变更）、外部性（未被代表的第三方损害）。

代谢平衡摄入与排泄：只摄入不排泄是肥胖（记忆通胀、检索失效），只排泄不摄入是僵化（技能腐化、重复犯错）。**代谢率必须与生长率匹配**——这是本轮"生长"概念缺的调节旋钮。

【确定】免疫有两种对称失败，多数框架只防一种：免疫缺失（污染进系统）与免疫过强（新变异被当入侵，系统僵化）。红队被同化是前者，一切新提案被"风险太高"驳回是后者。二者都需要一个**异议配额**：每周期必须有部分被驳回的提案进入复审，否则免疫系统本身不可检验。

### 4.7 责任：集群只能承担程序责任

【确定】集群不是可被制裁的主体。故责任必须二分：**程序责任**（可归集群——是否执行控制、是否披露不确定性、是否在越界前升级、是否保存证据，可核查可度量）与**实质责任**（不可归集群——损害是否可接受、目标是否值得、遗留由谁承担，必须由具名人类持有）。

BRIEF 所列"集群无责任主体"的正解，不是给集群安一个主体，而是承认集群永远只能负程序责任，并把实质责任显式、具名地固定在人类身上。任何"集群共同负责"的表述都是责任稀释的语法。

## 5. 学习与验收基线：对象冻结、三轨、门禁、回滚

### 5.1 开发期必须允许什么、必须延后什么

| 行为 | 开发期 | 理由 |
|---|---|---|
| 观察、反例、现场保全 | 必须允许 | 学习原料 |
| 候选、技能草稿、沙箱实验 | 必须允许（写候选区） | 常设学习的实体 |
| r1/r2/r3 纠错、止损、隔离、阻断 | 必须允许 | 安全优先于流程 |
| 改判据/权限/门禁/目标 | 延后且走权威 | 这是改规则，不是学习 |
| 晋升 L0/L3、改共享基线 | 延后到晋升门 | 影响未来所有项目 |
| 权重级/控制流级变更 | 延后且重新验证 | 不可审计、不可回滚 |

**判据按验收期冻结。** 每个验收期开始时取判据快照，期内提出的判据变更只对下一期生效。【确定】这是最便宜的防"边验收边改判据"机制：它保留持续提出改进的自由，只延迟生效时点；比 v0.4 的"等全量验收"温和得多，也比"靠自觉"硬得多。

### 5.2 三轨与四门

本轮所问的"双轨"（交付/学习）方向对但不够：学习轨内部还须再分候选与晋升，否则"候选"与"已生效"会混为一谈。

轨 A 交付（冻结基线，常规纠错）、轨 B 候选（持续写影子账，无权威）、轨 C 晋升（证据门槛 + 非同源复核 + 未参与样本验证 + 人类批准）。四门：候选门（可写）、证据门（样本与反例）、影响门（影响面与回滚路径）、权威门（谁有权批准）。

### 5.3 晋升门的新判据：可证伪声明

【推测】这是我认为本轮最值得引入的机制：每条被晋升的规则必须附带一个它承诺改变的观测量（如"此规则应使同类根因复发率下降"）；若该量不降，规则自动进入复审，默认降级。三个作用：把"学习"变成可被推翻的预测；让"规则数量"无法冒充能力；给退役一个触发条件，而不靠人记得清理。【存疑】它在小样本项目上可能失效，见 §14。

### 5.4 回滚

每个晋升项必须写明回滚触发条件（哪个观测量、什么阈值、谁判断）。没有回滚条件的晋升不是晋升，是永久变更。

### 5.5 生长成本账簿

本轮构想最缺的是一本账。概念级至少要记五项成本：**变异成本**（探索、红队、多方案、影子运行，天然无上限且先付）；**验证成本**（主导项，随保留物组合数二次增长——第 n 条规则要与其他 n−1 条检查冲突）；**维护成本**（每条 L0 需周期复审，条目增长与复审周期固定则负担无界）；**协调成本**（异质成员接口数平方增长 + 翻译损失）；**注意力成本**（人类裁决机会成本）。收益只有三项：复用（须真正被检索且适用，绝大多数记忆条目从未被读）、方差下降（价值体现在避免尾部损失，故极易被低估、先被砍）、期权价值（失败项目的教训，可能一文不值且持有有成本）。

【推测】由此得出两条反直觉判断：第一，**删减不是卫生，是正确性要求**——L0 有 n 条时潜在冲突对为 O(n²)，不删则冲突检查成本超过单条价值。第二，**"不是每个失败都值得复盘"**——当归因成本高于信息价值时，只做墓碑才是诚实的（见 §8）。

### 5.6 停止规则（生长模型的必备件）

- S1 递减停手：新晋升条目在随后 N 个任务中未被检索使用，则停止晋升，转入整固期。
- S2 验证债务上限：未验证候选超过上限即冻结新晋升，只许观察。
- S3 预算熔断：学习/进化开销超过项目预先声明的份额即降级为"只记录不晋升"。
- S4 冲突率停手：新增规则与既有规则冲突数超阈值即停止新增，强制整固（r4 维护）。
- S5 不降即停：晋升规则承诺的观测量不降，规则自动降级并复审。

【确定】没有这五条，"学习是常设责任"等于给一个无底洞发放永久授权。

## 6. 人类三项权力的操作化与防架空

- **方向**：能说出"为什么做""不做会怎样"，以及至少一个"即使做成了也不算成功"的情形。
- **目标**：可判定判据 + 非目标 + 可接受损害边界 + 谁是用者。
- **真实使用验收**：由非执行者的真实使用者为真实目的使用，保留失败、代价、非理想路径；人类判断意义与外推边界。【确定】"真实"的最低条件是使用者不是执行者的复述工具。

防架空六条：反选项义务、原始证据直达、零修改率告警、议程插入权、节奏暂停权、摘要与判断分离。

**零修改率是最重要的传感器。** 若人类连续多次未作任何实质修改，这不是效率高，是门禁已死。健康的裁决系统必须有可观察的分歧。它也是天然反 Goodhart 的指标：要提高它只能真的不同意，而 agent 无法替人类制造不同意。

## 7. 目标生长与目标漂移

区分不靠内容，靠程序与举证责任：

| 维度 | 合法生长 | 漂移 |
|---|---|---|
| 触发 | 新证据（真实使用、反例） | 执行压力（做不完、太难） |
| 方向 | 更贴近价值，通常更难满足 | 更容易满足 |
| 留痕 | 版本化，保留沿革 | 静默替换 |
| 效果 | 原失败仍记为失败 | 原失败消失 |

两条可操作检验：**反事实检验**——如果没有这段实现经历，我们还会提出这个新目标吗？若不会，这不是目标发现，是妥协被追认为发现。**方向不对称**——变更使目标更难满足时，举证责任在人；使目标更容易时，举证责任在提案方且门槛更高。【推测】粗糙，但挡住最常见的一种洗白。

版本联动：目标版本 → 判据版本 → 验收基线版本 → 在途任务。任一上游变更，下游全部标 STALE 并重新界定；不允许"部分继承"。历史验收记录不改写，新版本产生新代次。

## 8. 生命周期、阶段门禁与四种出口

阶段：播种（目标/非目标/可接受损害/反例/预算/停止规则）→ 生长（分批交付 + 学习候选）→ 结果（集成 + 真实使用）→ 落地（四问 + 责任/成本）→ 维持 → 休耕 / 堆肥 / 封存 / 退役。

各阶段的差别不在做多少，而在**谁在判断**：播种期人类密度最高；生长期最低，只裁例外与不可逆；落地期再次升高（因为要交负担）；维持期最低但必须有具名运维人。

**失败/中止/放弃的学习出口是终止门，不是验收门。** 它不产生"已验收"，只产生三件事：证据封存、失败归因（允许"归因不明"）、腐熟处理。三个条件：

1. **腐熟期**：失败教训不得立即晋升，须经一段时间与一次非同源复核。理由：失败当下的归因几乎总是情绪化且过度自指或过度他指。【确定】生粪不能直接上田。
2. **无害化检验**：归因必须区分目标错/判据错/执行错/环境错，且必须至少提出一个"这不是任何人的错，是假设错了"的可能性。
3. **墓碑最低标准**：记录"我们曾相信 X，X 被证伪"。一条，便宜，可检索。

**防洗白两条**：交付结果与学习产出分列报告，不可相互抵消；"我们学到了很多"只能放附录，不能作项目结论。

## 9. 失效模式（24 条）

| # | 失效模式 | 触发机制 | 后果 | 严重度 | 概念级补偿 |
|---|---|---|---|---|---|
| 1 | 生长义务化 | 生长成为常态职责且无不生长状态 | 永不定版，范围持续膨胀 | 极高 | 设"不生长"为合法默认态，生长需提案与预算 |
| 2 | 学习预算无主 | 学习开销不计入项目账簿 | 挤占交付且无人负责 | 高 | 学习开销单列并设上限份额 |
| 3 | 变异无选择 | 探索预算无上限、无人有权砍 | 候选爆炸，无一可交付 | 极高 | 变异预算封顶；每期强制杀死若干候选 |
| 4 | 验证债务累积 | 候选增速快于验证 | 未验证能力被使用 | 极高 | 超上限即冻结新晋升 |
| 5 | 记忆通胀 | L0 无配额无置换 | 检索失效、规则冲突 | 高 | 写入配额 + 满额具名置换 |
| 6 | 生粪上田 | 失败教训未经腐熟即晋升 | 错误归因污染跨项目知识 | 极高 | 腐熟期 + 非同源复核 + 无害化检验 |
| 7 | 失败洗白 | 用学习产出替代未交付结论 | 失败项目在账面上成功 | 极高 | 交付与学习分列，不可抵消 |
| 8 | 学习免责令 | 只要产出教训即免责 | 项目组合全是"学习型成功" | 高 | 学习产出不计入交付 KPI |
| 9 | 伪多样性 | 同模型多席被计为异构验证 | 共同盲区被"多席一致"确认 | 极高 | 以错误相关性/分歧率定义异构 |
| 10 | 红队同化 | 红队共享材料、奖励与节奏 | 异议被"建设性化" | 高 | 独立取材与独立奖励；异议配额 |
| 11 | 无淘汰 | 坏 agent/坏技能只增不减 | 代谢停滞、成本上升 | 高 | 淘汰率作为健康指标；淘汰留理由 |
| 12 | 免疫过强 | 一切新变异被视为风险 | 僵化，进化停滞 | 中高 | 被驳回提案定期强制复审 |
| 13 | 责任稀释 2.0 | "集群决定"掩盖无主体 | 事故无人承担 | 极高 | 程序责任归集群，实质责任具名归人 |
| 14 | 议程架空 | 人类只裁选项，选项由集群构造 | 人在别人的框里签字 | 极高 | 反例指定权 + 反选项义务 + 议程插入权 |
| 15 | 落地被验收冒充 | 验收通过即宣布落地 | 无人运维、无接手、无退役路径 | 极高 | 落地四问 + 运维方共同接受 |
| 16 | 目标生长洗白 | 事后改目标使原偏离消失 | 历史失真，问责消失 | 极高 | 沿革不可改写 + 反事实检验 |
| 17 | 长期观察替代结论 | 以"还要再看看"推迟判断 | 永不结项 | 高 | 观察期须有期限、责任人与终止条件 |
| 18 | Goodhart：学习数量 | 以规则数/技能数/记忆条数评价 | 活动量冒充能力 | 高 | 证伪声明 + 退役率 + 复发率 |
| 19 | 沉默失败不学 | 只学"被判据看见"的问题 | 街头灯效应，真实缺陷不可见 | 高 | 沉默失败抽查；外部信号权重高于内部 |
| 20 | 自噬 | 知识来源以自身产出为主 | 多样性坍塌、错误放大 | 极高 | 来源份额指标 + 外部输入比例下限 |
| 21 | 外部性无主 | 真实使用伤害未参与方 | 内部完成、外部不可接受 | 极高 | 外部性账；受影响方或合法代表参与接受 |
| 22 | 合规冲突 | 监管要求冻结配置，生长要求变更 | 无停手与解释机制 | 高 | 变更只能产生变更请求，不得直接改变行为 |
| 23 | 小项目压垮 | 三元全套用于数小时任务 | 仪式成本 > 失败成本，被绕过 | 中高 | 明确不适用阈值；默认轻量 |
| 24 | 工作区不可读 | 只写结论不写理由与现场 | 人类只能看摘要 | 高 | 冷启动测试 + 删除测试 + 原始对象直达 |

最危险的组合不是单条，而是链条：**生长义务化 → 学习预算无主 → 验证债务累积 → 名义晋升 → 伪多样性确认 → 零修改率签字 → 验收通过即宣布落地。** 全链无人说谎，却稳定产出"一直在变强"的假象。

## 10. 度量：生长是否真实发生

五类健康度，每类至多两个指标，且每个"越多越好"的指标必须配一个反向指标——否则它就是下一个 Goodhart 入口。

| 维度 | 指标 | 反向/警戒 |
|---|---|---|
| 交付健康 | 落地后需人工救火频次 | 未验证能力暴露量（应为 0） |
| 学习健康 | 同根因复发率下降 | 规则退役率应 > 0：从不退役即未在学习 |
| 进化健康 | 未参与样本的再验证覆盖率 | 变更回滚率应稳定而非趋零 |
| 工作区健康 | 冷启动接手成功率 | 归档条目仍被检索的比例（应近零） |
| 人类决策健康 | 人类实质修改率应 > 0 | 裁决等待时间不应为 0（0 即未在裁） |

【确定】任何可以被"多做"改善的指标都必须配一个"少做也合法"的出口，否则系统只会朝指标方向长，而不是朝价值方向长。

## 11. 最优异 5 点、最致命 5 缺陷、冗余与简化

**最优异五点及成立条件**：一，学习常设化 + 对象冻结（条件：候选区与权威隔离真实存在）；二，工作区升为落地区，可维/可接/可退（条件：落地权含运维方）；三，集群概念迫使正视错误相关性（条件：用分歧率与来源份额度量而非席位数）；四，生命周期给失败与停滞以合法位置（条件：腐熟与墓碑机制）；五，人类注意力成为显式预算（条件：人类保留提问权）。

**最致命五缺陷**：一，人类三项权力全为回答型，提问权留给集群，且比 v0.4 的门禁更隐蔽；二，生长无预算无停止规则，"不生长"无合法地位；三，撤销时间冻结却无对象冻结替代，判据污染风险回升；四，集群无淘汰、无具名主体，"集群"可能只是多几个 agent 加责任稀释 2.0；五，失败学习出口若设计不良，不是洗白失败就是腐熟不足污染 L0。

**必要制衡（不可删）**：目标与判据分离、自验与独立验收分离、证据与记忆分离、学习与权威分离、落地与验收分离。

**真冗余（可删/可并）**：每阶段重复的"目标对齐仪式"（改为判据快照变更时触发）；每个候选都写完整教训（多数只留墓碑）；每个项目都晋升 L0（默认不晋升，晋升是例外）；无先验差异的多角色（角色可并）；技能与记忆双份维护（单一出处）；超过五个指标的仪表盘（无人看）。**原则**：概念不可合并，载体可以合并；判断不可合并，证据可以复用；权威不可委托，劳动可以委托。

## 12. 适用边界：哪些场景不该用三元生长模型

| 场景 | 为什么不成立 | 应换的形态 |
|---|---|---|
| 一次性/高度特化 | 复用收益趋零，记忆只有成本 | 只留交付轨，明确"本项目不产生可泛化经验" |
| 极小任务/极短周期 | 仪式成本 > 失败成本 | 轻量三件：目的、执行、一句验收 |
| 强实时 | 门禁延迟不可接受 | 运行时自治 + 事后审计，不做前置验收 |
| 强合规/强安全 | 生长与"变更受控"直接冲突 | 学习只产"变更请求"，不产生行为改变 |
| 验证成本 >> 执行成本 | 证据链闭不了 | 不变量 + 抽样 + 长期观察，完成声明只覆盖过程 |
| 反馈周期 > 项目周期 | 无法验收价值 | 只验过程与不变量，显式声明价值未知 |
| 多利益相关方冲突 | "人类"不是单一主体 | 先立治理结构，agent 只做事实与选项 |
| 高不可逆风险 | 不允许变异-选择循环 | 预演-批准，禁试错 |
| 需要单一权威解释（法务/医疗/审计） | **趋同是合规要求，多样性是缺陷** | 关闭异质性，只保留"权威解释 + 一致性检查" |
| 对抗性环境（安全） | 记忆是投毒面，学习是攻击面 | 学习离线、隔离、人审 |

【确定】最后两行是本报告最容易被"多样性总是好的"这种直觉吞掉的判断：在需要单一权威解释的领域，异质性是风险；在对抗环境里，学习通道本身就是攻击面。三元生长模型在这两类场景中不是"需要裁剪"，而是"方向相反"。

## 13. 最小 v0.5 基线与人类裁决问题

十条基线（★ = 任何降级都不可删）：★1 人类价值根（谁接受损害）；★2 目标与判据的版本绑定；★3 自验非验收（最低限度：换上下文）；★4 真实使用，或明确声明"未验证"；★5 停止权与预算上限；★6 实质责任具名到人；★7 证据只追加、不可改写；★8 学习不得改判据/权限/门禁；9 落地四问与运维方接受；10 判据按验收期冻结。

需要人类裁决的问题：一，是否承认"提问权/反例指定权"为第四项不可转移权力？二，学习开销上限占项目预算的比例由谁定、按什么标准？三，落地权是否必须包含未来运维方的同意？四，失败项目是否设正式终止门，其归因到什么深度即可封存？五，权重级变更是否一律视为"换主体"并重新验证？六，哪些场景明确宣布"不使用三元生长模型"（我倾向于至少包含上表后四行）？

## 14. 自我反驳：这个框架最可能在哪里失效

1. **我的核心机制依赖样本量，而真实项目样本不足。** 可证伪声明、复发率、退役率都要求同一根因出现足够多次才能区分"规则有效"与"噪声"。中小项目上，我的整套证伪机制会退化为形式——写着观测量，没人真的测，或者测了也说明不了什么。**这是最可能的失效点：我的框架在"样本充足"假设下最自洽，而真实项目恰恰样本不足。**【推测】
2. **我要求停止，但没有人有动机执行停止。** 停止规则需要一个"停止倡导者"，我的框架里没有这个角色。执行停止的人会被视为阻碍；预算持有者通常也是希望项目继续的人。这是一个真实缺口，可能应设"止损官"或把停止权交给不参与交付的预算方。【存疑】
3. **我假设人类能行使反例指定权与议程权。** 这需要领域知识与时间。在人类本来就不懂的场景，所谓"低成本实质参与"仍是空的，我的方案只是把形式化从"读文档"换成"说一句反例"，形式化的本质没变。
4. **我对可审计载体的偏好可能低估权重级学习。** 若能力跃升主要来自权重与先验，我的框架会系统性拖慢最重要的进化，并用"可审计"的美名把它挡在门外。这是一个保守性偏差，我不确定它是否值得。
5. **我的经济学论证是推理，不是实测。** 验证成本二次增长、记忆维护无界，在工具化之后可能被压到近线性，从而削弱我"必须删减"的结论。若二次项可被工具消除，我的记忆预算与具名置换就退化为不必要的官僚。
6. **我的反例倾向本身有偏。** 我倾向于把"失败"看作比"停滞"更可控，但在竞争性领域，停滞的代价可能远高于失败。我的框架整体偏保守，可能在高变化环境中成为束缚。

【确定】以上六条中，第 1 条与第 3 条是我认为最可能被现实证伪的；第 2 条是我承认的结构缺口而非可辩护的取舍。
