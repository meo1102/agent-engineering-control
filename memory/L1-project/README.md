# L1 项目记忆（本项目）

## 放什么

- 目标契约（当前版本与变更历史）；
- 关键决策与理由（决策记录）；
- 术语表、约束、里程碑；
- 风险台账、错误台账索引；
- 验收判例、收敛记录。

## 维护规则

- 目标契约变更必须走变更记录，旧版本保留；
- 决策记录只记"为什么"，不重复"是什么"；
- 错误台账只放摘要，全文在区域记忆；
- 收敛时做一次清算：晋升、归档、标注失效。

## 模板

### 目标契约

```markdown
## 目标契约 v0.1
- 目的（为什么做）：
- 成功判据（可观察）：
  1.
  2.
- 非目标（明确不做）：
- 边界与约束：
- 授权与责任：目标所有者 / 验收者 / 仲裁者 / 人类门禁
- 验收方式：
- 时间盒：
- 失败预案：
- 变更记录：
```

### 决策记录（ADR 风格）

```markdown
## DR-000 标题
- 背景：
- 选项：
- 决定：
- 理由：
- 后果 / 代价：
- 关联目标判据：
- 日期 / 决策者：
```

### 错误台账（索引）
