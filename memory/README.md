# 记忆区（概念骨架）

> 这不是实现，而是分级记忆的**结构示范**：说明每层放什么、谁维护、如何晋升与退役。真实运行时，形式可以完全不同。

## 分层

| 层 | 范围 | 变化速度 | 证据门槛 | 维护者 |
| --- | --- | --- | --- | --- |
| L0 元知识 | 跨项目 | 慢 | 最高（跨 ≥2 项目 + 反例 + 人类批准） | 人类 + 记忆管理员 |
| L1 项目记忆 | 本项目 | 中 | 中（项目内复现 + owner 批准） | 项目记忆管理员 |
| L2 区域记忆 | 开发/验收/收敛/协作 | 快 | 低（单次事件即可记录，但不晋升） | 区域负责人 |

## 生命周期

```
事件发生 → 写入 L2（观察）
   │ 同根因/同模式复现 ≥N 次
   ▼
晋升 L1（项目级教训/判例/决策）
   │ 跨 ≥2 项目复现 + 反例检验 + 人类批准
   ▼
晋升 L0（元知识）
   │ 失效/被证伪/长期未复审
   ▼
归档（保留原因与替代者，不删除）
```

## 条目最小字段

`ID · 层级 · 区域 · 标题 · 内容 · 来源 · 时间 · 置信度 · 适用范围 · 反例 · 复审日期 · 所有者 · 状态`

## 三条铁律

1. **样本为 1 的错误只能成为观察，不能成为规则。**
2. **没有来源与置信度的记忆，等于谣言。**
3. **淘汰不是删除，是归档并留下原因。**
