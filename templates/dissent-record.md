- **一句话主张**：

- **不确定性**（不知道什么、置信度、可能反证）：
- **影响**（谁/什么会受损、可逆性、范围、紧迫性）：
- **建议替代方案**（可选，但鼓励）：
- **什么会改变我的判断**（可证伪条件）：
- **相关产物 / 决策 / 门禁**：
- **请求动作**：调查 / 暂停 / 修改 / 复审 / 升级 / 停止

## 5. 质量检查

- [ ] 有明确主张，而不是只有情绪或评价
- [ ] 有事实依据，或明确标注为弱信号
- [ ] 有影响说明与严重度
- [ ] 有具名处理人与裁决人
- [ ] 裁决有理由，且已回告提出者
- [ ] 已进入异议台账与相关门禁的异议审查
- [ ] 若为 S1/S2，人类已实际阅读原始内容（不是只看摘要）
